How to add photos of your sister:

1. Drop the photos you want to display into this "images" folder.
2. For the best look, it's great if they are relatively square or you can just let the website crop them automatically (it will make them perfect squares on the site).
3. Name them exactly as they appear in your index.html file (e.g., photo1.jpg, photo2.jpg, etc.) OR open your index.html file in a text editor and update the filenames in the HTML to match whatever you named your photos.

Example:
If you have a photo named "monisha_graduation.jpg", drop it in this folder.
Then open index.html, find the gallery section, and change:
<img src="images/photo1.jpg" ...>
to
<img src="images/monisha_graduation.jpg" ...>
